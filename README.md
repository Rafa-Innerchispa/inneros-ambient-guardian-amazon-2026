# InnerOS Ambient Guardian

**Alexa+ becomes the voice of a local-first AI guardian that connects Ring, cameras and IoT, executes approved actions, and returns verified evidence in real time.**

Amazon Build, Ship, Shape Developer Hackathon 2026. Primary track: Alexa+. Ring integration, AWS Builder and Open Source mini challenges are part of the build plan.

This repository is being built in public during the hackathon. Core design principle: understand first, require bounded approval for physical actions, execute, verify, and return evidence.
